# MetalHops

An Untappd-style app for finding metal/rock bars and pubs around the world: where rock plays, the beer is good and the food is better.

## Structure

| Folder | Purpose |
|---|---|
| `android/` | Android app (Kotlin) |
| `ios/` | iOS app (future) |
| `backend/` | Backend API |
| `docs/` | Product, architecture and API docs |
| `design/` | Wireframes and assets |
| `infra/` | Infrastructure / deployment config |
| `scripts/` | Dev and CI helper scripts |

## Branching

- `main`: stable, release-ready
- `dev`: integration branch; feature branches (`feature/*`) merge here via PR

# Keep restriction records after User deletion

User deletion ends a User's Profile, Reviews, Check-ins, Profile Reports, and
report quota. A restriction record is kept. It remembers the decision, the
reason, the note, and any expiry, and it does not remember the Username or
display name. After deletion it remains without that User's identity.
Destroying the record with the User would erase the fact that a Platform
Moderator placed, replaced, or ended a restriction. The record is not a
Profile and has no public identity. The records that remain are the Profile
and Review moderation decisions. A standing Commentary restriction ends with
the User. A Venue's eligibility decisions remain as that Venue's history and
are not a Restriction record.

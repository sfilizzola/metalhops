# An ending Restriction record carries the explanation that began it

Ending a restriction is its own Restriction record: withdrawing a rename
requirement, clearing a Community Suspension, lifting a Commentary
restriction, or a Community Suspension expiring. That record carries the
Restriction explanation of the restriction that ended. The Platform
Moderator supplies no new reason or note.

A reason written for the ending was rejected, and so was an empty reason.
The ending has to stay readable as the close of a particular restriction,
using the same explanation already kept when a Profile restriction ends.

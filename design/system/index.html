Backline

The MetalHops design system: stage-monitor clarity under tungsten light. Oxblood black and a single amber, blackletter for headings only, IBM Plex Sans for everything people need to read in a loud, dim bar. Every value comes from tokens.json; tokens.css and the tables on this page are generated from it. Venues, people and Reviews shown here are sample content.

Foundations

Color

Dark-first, with a light mode. Names follow Compose Material roles so Android and iOS can map them one to one. All values are oklch() inside the sRGB gamut; the build checks this.

TokenDarkLightCompose role

Contrast, measured

WCAG 2.2 contrast ratios, computed from the token values by build-tokens.mjs; the build fails if a pair drops below its minimum. Text needs 4.5:1. Outlines, focus rings and selected borders are UI parts and need 3:1. Disabled controls are exempt and drawn at reduced opacity. Focus rings sit 2 px outside the control, so they are measured against the surface behind it.

Type

Grenze Gotisch for display and title only: Venue names, page and section titles. Never body, labels or numbers. IBM Plex Sans for everything else. Body is 17 px so it reads at arm's length. All numbers use tabular figures.

Space, radius, borders

Minimum tap target: 48 px (--size-tap-min), above the 44 px floor. The Check-in button is 56 px.

Elevation

Shadows barely read on a dark surface, so depth comes from two things together: each level steps the surface lighter and adds a hairline ring. Shadows only reinforce it. In light mode the ring and shadow do the work.

Motion

Short and purposeful: state changes use fast, cards and panels base, entering sheets and the Check-in confirmation slow. With reduced motion, durations go to zero. Select a row to play it.

Components

Buttons

Primary for the one main action on a screen, secondary for alternatives, ghost for low-emphasis actions, destructive for removing things. All are at least 48 px tall. Hover and pressed states mix toward on-surface, which only ever raises text contrast.

Text input

Label above, help text below; an error replaces the help text. Sign-in errors are generic and sit above the form, so they never reveal whether an email is registered.

Venue card

The whole card is one link to the Venue page. The name is in the display face; everything you scan for (Venue type, city and country, Genres, rating, Review count, distance) is in Plex Sans. The photo slot is 16:9; without a photo the card simply starts at the badge.

Rating

Read-only average: one decimal, a five-segment meter that fills partially, and the Review count. Input: a whole number from 1 to 5 (5 is best), required on every Review. It is a radio group: arrow keys move, each star is a 48 px target, and the chosen value is also written out as text.

Genre tag

Two forms. A static tag (small radius, filled, not clickable) labels a Venue. A filter chip (pill, outlined, 48 px tall) toggles a Genre in search; selected chips gain a check mark as well as colour, so state never relies on colour alone.

Verified Venue badge

Means one thing: a Platform Moderator accepted this Venue for the public catalogue. It says nothing about the owner, so it uses a plain check mark and the words “Verified Venue”. Never a shield, crown, seal or rosette, and never the words “official”, “owner” or “claimed”. Tapping or hovering it explains what it means.

Check-in button

The biggest target on a Venue page: 56 px tall, full width on phones. After a Check-in it turns into a done state with the time, in the success colours, and stops being pressable. Try the interactive one.

Identity

Avatar, display name (1 to 80 characters) and @username (3 to 30 letters, digits or underscores). Without a photo the avatar shows initials. Long names truncate with an ellipsis. On one line the @username gives way first, but at least its first 8 characters stay visible; the full size gives each its own line.

Review item

One Review per User per Verified Venue: a rating, optional commentary, the author and a date. When a moderator removes the commentary, the rating stays and a quiet note replaces the text.
